3 Excel 对照改名 选文件夹时，若有 list.xlsx 会自动载入

点击或拖入 Excel / CSV xlsx / xls / csv / tsv · 仅本地读取

对照结果 = 新名主列 +（有附加列时自动加 _附加信息）+ 原扩展名。同一原名下的 .wav / .mp4 / .TextGrid 会一起改。主名比对会折叠空白；如果只是标点不同，去掉标点后又能唯一对上一个文件，也会匹配。只打开 list.xlsx 时读不到旁边的 mp4，需要先选择它所在的文件夹。统一前缀、后缀、日期、简繁等请用下面的规则，会叠在对照结果上。

没有 Excel？也可以粘贴对照表（每行：原名 + 制表符或逗号 + 新名）
