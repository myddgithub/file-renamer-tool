📁 文件批量重命名工具

选一次文件夹，Excel 对照和规则可同时用在同一批文件上 → 预览 → 一键应用（可回滚）。全部在本地完成。

1 选择文件夹

尚未选择文件夹
💡 选一次即可，下面的 Excel 对照和命名规则都作用在这个文件夹。Chrome / Edge 可直接改磁盘文件，也可把文件夹拖到虚线框。若浏览器不支持，可用「选择多个文件」仅预览。

3 配置命名规则（可叠在 Excel 对照之后）

2 用 Excel 对照改名（可选）

点击或拖入 Excel / CSV
支持 .xlsx .xls .csv .tsv · 表格只在浏览器里读，不会上传

对照结果 = 新名主列 +（有附加列时自动加 _附加信息）+ 原扩展名。同一原名下的 .wav / .mp4 / .TextGrid 会一起改。统一前缀、后缀、日期、简繁等请用下面的规则，会叠在对照结果上。

没有 Excel？也可以粘贴对照表（每行：原名 + 制表符或逗号 + 新名）

4 预览与应用

原文件名 新文件名（可双击修改）
请先选择文件夹
先按 Excel 对照（若已上传），再套用已勾选的规则。双击新文件名可单独改一条。橙色=目标名冲突，红色=名称不合法。
已选 0 项 将改名 0 冲突 0 错误 0 未匹配 0

5 回滚（撤销）

操作历史（已写入文件夹）
原名称新名称
暂无操作记录
⚠️ 记录保存在该文件夹的 .rename_history.json。关掉浏览器后再打开本工具、选回同一文件夹，仍可撤销。回滚会把文件从「新名称」改回「原名称」。撤销上一次 = 回滚最近一次批量操作。全部回滚后会删除这份记录。
🔒 所有操作均在本地浏览器完成，不会上传任何文件。重命名前请确认预览结果。快捷键：Ctrl+Enter 应用。
